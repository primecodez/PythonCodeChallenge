Special Sequences (\)
You will also see a lot of letters paired with a backslash. These are shortcuts for common character types:

\d : Matches any digit (0-9).

\D : Matches any NON-digit.

\w : Matches any word character (letters, numbers, underscores).

\W : Matches any NON-word character (like punctuation).

\s : Matches any whitespace (space, tab, newline).
